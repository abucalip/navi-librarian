# Docs

Start at [`ACTIVE_WORK.md`](ACTIVE_WORK.md) (the task queue) and [`PROJECT_STATUS.md`](PROJECT_STATUS.md) (latest state and next action).

| Where | What |
| --- | --- |
| top level | Standing documents: `ACTIVE_WORK`, `PROJECT_STATUS`, `ARCHITECTURE`, `DECISIONS`, `REQUIREMENTS`, `TEST_PLAN`, `DEVELOPMENT_WORKFLOW`, `LOCAL_UI_TESTING`, `UI_DESIGN_RULES`, `DEPLOYMENT`, `SESSION_CONTEXT_SEARCH` |
| [`contracts/`](contracts/) | Interface contracts for the server, the Android and macOS clients, search, radio and recommendations |
| [`plans/`](plans/) | Plans, proposals and roadmaps that still have unbuilt steps or open decisions |
| [`design/`](design/) | Mockups, tokens and design tooling; the specs for the UI |
| [`architecture/`](architecture/) | Generated inventories (test inventory, dependency map) |
| [`archive/`](archive/README.md) | Finished plans, proposals, research and history; evidence, not instructions |

When a plan's build is finished, move it to `archive/completed/` and fix its links in the same change.
