Android Insights: Taste card

One compact card in the Insights list. It shows the server's headline, the top three movers as chips, and a Recent / All-time toggle. Tapping opens a bottom sheet with the full bars. Fixture data, not real listening.

Theme
What to judge
  • The card stays one screen-third tall, so it sits among the other Insights cards without taking over.
  • The headline comes from the server as headline.text. The client only draws it and never builds sentences.
  • The sheet repeats the macOS cards in a smaller form: ghost bar = all-time share, solid bar = recent, tick = all-time share.
  • Thin and empty states match the Mac wording, so one string set can serve both.
