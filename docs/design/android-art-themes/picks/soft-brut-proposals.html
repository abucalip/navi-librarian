Discair Soft Brut Dashboards

Subtle neobrutalist theme, four dashboards

Android, phone width. Every proposal keeps the neobrutalist kit from the local folder (ink outline, hard offset shadow, pastel fill, mono labels) but turned down: 1.5dp outlines, 3dp shadows, one accent, and the outline goes on the artwork first. Covers and artist photos are drawn stand-ins; the app uses the real ones.

Scroll inside each phone. Reply with one code (N1 to N4), or a mix such as "N2 with the nav from N4".
