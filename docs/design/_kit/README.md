# Shared mockup kit (Bento and Index)

Design tooling only: nothing in the app imports it and no test collects it. Both theme packages, [`../bento/`](../bento/) and [`../index/`](../index/), use it from their `_src/build.py` and `_src/check_contrast.py`.

| File | What it is |
|---|---|
| [`kit.py`](kit.py) | <ul><li>Sample data: the same albums, artists, tracks, stations and Paths steps in both themes.</li><li>The icon path table, with the Kotlin names that match `ArtIcons`.</li><li>The `PaletteTest` contrast maths.</li><li>The page wrapper (frames of 360 × 780dp side by side) and the Chrome PNG render.</li></ul> |
| `art.css` | Generated by either build script: the stand-in covers (`.c-<key>`) and artist photos (`.p-<key>`), drawn in CSS. **Not for the app**, which shows real artwork |

Changing `kit.py` changes both packages; rebuild both with their `build.py`.
