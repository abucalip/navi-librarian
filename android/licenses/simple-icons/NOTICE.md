# Simple Icons: vendored platform marks

Source: the `simple-icons` npm package, version 16.35.0, files `icons/applemusic.svg`, `icons/spotify.svg` and `icons/bandcamp.svg`. Each file is unchanged except that the root `<svg>` element has a `fill` attribute set to the brand colour the album modal used before this change (`#FA243C`, `#1DB954`, `#1DA0C3`).

Licence: the icon drawings are released under CC0 1.0 Universal (`LICENSE.md` in this folder, copied from the package). Simple Icons states that this does not necessarily cover every icon, and that the marks are trademarks of their owners (Apple, Spotify, Bandcamp). The licence file does not grant any trademark right. Use here is only to identify each service's search link, with the service name shown in text beside it.

Not vendored: ListenBrainz and Qobuz. Simple Icons has no mark for either (checked in `simple-icons` 16.35.0; it has `musicbrainz`, which is a different service and is not used for ListenBrainz). No clear licence was found for a ListenBrainz or Qobuz logo: the search turned up only third-party icon sites, and no official brand kit for Qobuz. Those two links keep a text label only, and no logo is fetched from a third-party host.


## Added with the album page links

`deezer.svg` and `musicbrainz.svg` are `icons/deezer.svg` and `icons/musicbrainz.svg` from `simple-icons` 16.35.0, unchanged except that the root `<svg>` element has a `fill` attribute set to the brand colour (`#A238FF`, `#BA478F`). The same CC0 notice and trademark caveat as above apply.

`qobuz.svg` and `listenbrainz.svg` are **not** the services' logos. Simple Icons has no mark for either (checked in 16.35.0), and no licensed mark was found. They are plain monograms drawn for this app (a ring with a Q, a rounded square with "LB") so that a logo-only button still has a distinct mark. Replace them if the owner supplies the official marks.
